# 🚌 Online Bus Ticket Booking System

## 📌 Project Description

The **Online Bus Ticket Booking System** is a web-based application that allows users to book bus tickets online easily. Users can check bus availability, select seats, and confirm bookings.

----------------------------------------------------------------------------------------------

## 🚀 Features

* User & admin Registration & Login
* Bus Search
* select a available seate
* Seat Booking
* Ticket Confirmation
* Admin Dashboard

--------------------------------------------------------------------------------------------------

## 🛠️ Technologies Used

* HTML
* CSS
* JavaScript
* PHP
* MySQL

-----------------------------------------------------------------------------------------------------------------------

## ⚙️ Installation Steps

### Step 1:

Download the project as a ZIP file

### Step 2:

Extract the ZIP file

### Step 3:

Move the extracted folder to:

```
C:\xampp\htdocs
```

### Step 4:

Open XAMPP Control Panel and start:

* Apache
* MySQL

### Step 5:

Open MySQL Shell (or phpMyAdmin)

### Step 6:

Paste and run the MySQL code (SQL file) inside the database

### Step 7:

Open your browser and run:

```
http://localhost/your-project-folder
```
